01 Point of sale · Desktop

Real world software
for a real bakery.

BakeryPOS is a Windows point-of-sale application built for La Jarochita, a working Mexican bakery — not a demo, and not a template. It runs on the counter hardware the shop already owns.

  • Platform Windows desktop
  • Built with .NET 8 · WPF
  • Pattern MVVM
  • Interface English / Español
  • Status In daily use

Built for and with La Jarochita Bakery in Passaic, New Jersey — a working panadería, not a hypothetical client. The software follows how they already run the counter.

The problem

A counter does not pause for software.

A bakery sells a lot of small things quickly, prints receipts and labels all day, and counts stock that changes by the hour. Generic retail software assumes a barcode on every item and a stable catalogue. A panadería has neither.

The shop also has its own print templates and its own counter hardware. Anything that ignores those becomes something staff work around instead of work with.

The approach

Split it along the seams that actually move.

BakeryPOS is one solution divided into parts that change at different rates. The till UI changes often; printing and data access rarely. Keeping them apart means a printer fix never risks the sales screen.

  • Register

    Touch product tiles by category, running cart, cash / card terminal / deposit.

  • Kitchen hub

    Today’s and tomorrow’s orders, low stock, and a printable kitchen list.

  • Production helper

    Make more, normal, make less and top sellers — suggestions, not instructions.

  • Stock keeping

    Daily stock check, quick adjustment, production count and movement history.

  • Owner analytics

    Best sellers by quantity and revenue, hourly totals, payment labels, date ranges.

  • Daily closeout

    End-of-day totals across payments, employees and categories, exportable to CSV.

Where it stands

Released, in use, and still being revised. The screenshots on this page come from release v1.4.0 running on a clean machine. The project ships tagged releases alongside a separate printer hotfix kit and the bakery's own machine and printer configuration — the ordinary evidence of software that is in service and getting fixed, rather than finished.
